## Current drift

- `.claudeignore` drops the JavaScript entries and adds `vendor/` and
  `coverage.out`. The adopter is a Go module.
- `.editorconfig` adds a `[*.go]` section setting `indent_style = tab`.
- The `Makefile` names the adopter's prose in `PROSE_FILES`, and a separate
  `HEDGING_FILES` list omits `README.md`. That file carries inherited MIT prose
  in the original author's voice.
- `sync-check.yml` keeps the template job layout and drops the AgentLint step.
- `hook-coverage-baseline.json` is the template's file, copied rather than
  regenerated. `--write-baseline` refuses to run as root. The adopting
  environment ran as root. Every file under `hooks/` is byte-identical. The
  template's CI-measured baseline therefore describes that checkout.

## Declined wiring assertions

Two suites carried assertions that hold only inside this repository. The
adopter removed those assertions under recorded active-human sign-off.
The adopter's `docs/template-drift.md` itemizes each one.

- `tests/test_check_conflict_markers.py`, class `WiringTest`. Five
  immutable-workflow tests removed, the `IMMUTABLE_WORKFLOW_PATH` half of two
  more removed, and `README_PATH` dropped from the two handoff loops. Those
  loops still assert against `AGENTS.md` and `plan/HANDOFF.md.example`.
- `tests/test_immutable_compliance.py`. Three scanner tests removed.
  `WorkflowPinningTest` replaced `ImmutableWorkflowTest` and preserves
  `test_external_actions_are_pinned_to_full_commit_shas`. That check reads the
  workflow directory through a glob. It needs no workflow fixture.

Both sets trace to the single declined workflow, apart from the `README_PATH`
case. The adopter's `README.md` documents a Go library rather than this
repository's policy.

## Note for the template

Three suites assert artifacts that exist only in this repository:
`test_policy_distribution.py`, `test_check_conflict_markers.py`, and
`test_immutable_compliance.py`. `test_advisory_workflow_wiring.py` and
`test_parallel_test_runner.py` also require an adopter to keep the exact
`sync-check.yml` filename and job shape.

`test_policy_distribution.py` needed no edit. The adopter satisfied it by
wrapping its own filled orientation in `repository-only` markers and retaining
the commented per-repo template. That is the marker contract working as
designed.

The other two needed edits. Adoption step 14 already anticipates this.
Separating repository-only wiring assertions from portable checker coverage
would let an adopter take the portable half untouched.
